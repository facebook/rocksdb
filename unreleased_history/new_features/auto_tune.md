Added experimental auto-tuning (`DBOptions::auto_tune`, `rocksdb/auto_tune.h`): RocksDB traces a short window of live traffic every period, with a checkpoint taken just before, and hands each window to a pluggable `AutoTuner` (RocksDB has no built-in tuner). Windows are written to `<DB directory>/auto_tune` by default (`AutoTuneOptions::tuning_dir`), which `DestroyDB()` deletes. Recommended option changes are checked by RocksDB (allowed options and bounds, step size, number of changes, and a confidence it computes from the tuner's confirmation windows), then reported through `EventListener::OnTuningRecommendation()` or applied with `SetOptions()`, watched and reverted on a broken constraint. `DBOptions::auto_tune` can be changed with `SetDBOptions()`: a new setting restarts the driver, and `mode=kOff` stops it. Also added `AutoTuneDriver` to run the same loop for an already open DB.
