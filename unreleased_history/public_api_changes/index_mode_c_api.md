Exposed the experimental index-selection surface in the C API: `rocksdb_block_based_options_set_index_mode()` / `_get_index_mode()` (with `rocksdb_block_based_table_index_mode_*` constants) and `rocksdb_readoptions_set_read_index()` / `_get_read_index()` (with `rocksdb_readoptions_read_index_*` constants). Previously C callers could only reach a subset of modes through the deprecated `use_udi_as_primary_index` / `fail_if_no_udi_on_open` setters, leaving `kStandardOnly`, `kCustomOnly`, and `kBuiltin` unreachable. An explicit `index_mode` now wins over those deprecated setters regardless of call order, matching the C++ behavior.
