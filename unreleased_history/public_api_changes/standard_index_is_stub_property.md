Added the `TableProperties::standard_index_is_stub` table property, set on SSTs written with `BlockBasedTableOptions::IndexMode::kCustomOnly` to record that their standard index is a placeholder and the file can only be read through a matching `user_defined_index_factory`. Exposed in the C API as `rocksdb_table_properties_standard_index_is_stub()` and in `sst_dump --show_properties` output.
