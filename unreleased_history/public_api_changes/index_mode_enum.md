Added `BlockBasedTableOptions::index_mode` (`kStandardOnly`, `kStandardDefault`, `kStandardRequired`, `kCustomDefault`, `kCustomOnly`) as the single control for which indexes an SST is built with and which one reads use. It supersedes the experimental `use_udi_as_primary_index` and `fail_if_no_udi_on_open` bools, which are now deprecated but still honored. The default preserves existing behavior.
